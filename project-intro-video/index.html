how it works / agent pipeline

一次分析，被拆成一支投研团队

每个 Agent 负责一个明确角色，最后由风控和总经理阶段收束成可执行的决策展示。

01 / question
问题理解
解析任务、股票代码、市场范围和风险偏好。
->
02 / information
信息分析
收集行情、宏观、A 股指标、资金流和公司信息。
03 / debate
多头 Agent
寻找估值修复、成长性、政策和资金催化。
04 / debate
空头 Agent
检视回撤、估值、盈利下滑和技术破位风险。
05 / decision
裁判 Agent
综合多空论点，给出更克制的判断。
06 / risk
风控复核
检查仓位、止损、资金规模和执行风险。
->
07 / output
总经理 + 交易计划
输出最终报告、价格触发条件和决策展示。

使用路径很短，分析链路很长

用户只需要提交任务和约束，系统负责把每个阶段的过程、摘要、原文和数据来源展示出来。

01
选择运行模式通用分析、每日扫描、指定板块或指定个股。
02
填写关键参数API Key、股票代码、板块、资金规模、风险偏好和任务描述。
03
查看实时流水线左侧输入，中间阶段进度，右侧切换摘要、原文和数据源。
04
读取最终决策输出完整报告、风险提示和价格触发式交易计划。
use cases / research scenarios

适合这些高频投研场景

它不是替代判断，而是把信息整理、观点交锋和风险复核做成可复用的工作台。

SCAN
A 股每日扫描从全市场候选池中筛出未来一个月更值得关注的标的。
SECTOR
指定板块分析围绕半导体、新能源、白酒等板块做强弱和机会判断。
DEEP
个股深度研究针对 600519、300750 等代码输出多空论点和交易策略。
COMMON
通用股票研究分析美股、ETF 或自定义标的的中短期投资机会。
requirement analysis / value

核心需求：追踪、复核、执行

从输入到最终计划，系统要把“为什么这么判断”留在界面里，而不是只给一个结论。

IN
输入清晰模式、标的、板块、资金和风险偏好决定分析边界。
DATA
数据可追踪信息分析阶段保留来源、成功状态和数据摘要。
OUT
结果可落地最终输出报告、触发价、风险提示和交易计划 JSON。
STOCK DECISION SYSTEM

让多 Agent 协作，变成一条可见的投研流水线。

适合辅助研究、复盘推理链路、比较不同标的和沉淀团队式分析流程。
