agent pipeline

一次模糊的投研问题，被拆成一条可检查的链路。

每个 Agent 只承担一个角色，让系统形成结构化辩论，而不是顺着单一观点往下编。

01 / parse

问题理解 Agent

判断你问的是个股、板块，还是全市场扫描。

02 / collect

信息 Agent

按边界收集行情、宏观、公告、板块和预测市场证据。

03 / upside

多头 Agent

只负责找上涨逻辑、催化因素和正向证据。

04 / downside

空头 Agent

只负责挑刺，找风险、反证和可能失效的条件。

05 / judge

裁判 Agent

把多空放到一起，不让系统只听自己想听的话。

06 / plan

总经理 Agent

把证据、反证和限制条件合成最终交易计划。

structured debate

上涨和下跌，都必须拿证据说话。

上涨不是因为大家都说看好，而是价格有没有走出来、成交有没有配合、财报和板块有没有共振。
