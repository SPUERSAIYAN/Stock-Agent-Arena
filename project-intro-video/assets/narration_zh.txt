做股票最坑的一件事，不是信息少，是信息太多。
研报、新闻、KOL、评论区，每个人都在说。
但投研里有一句话特别重要：不要看他说了什么，要看他做了什么。

所以我做了这个项目。
它不是把一堆观点丢给模型，让模型总结一下。
它真正干的事情，是先去找数据。
美股看日线、周线、期权、EDGAR 财报和公告。
A 股看腾讯行情、指数、本地股票池、板块概念，也能接 Tushare 和 mootdx。
宏观看美债收益率、汇率、恐惧贪婪指数、CME FedWatch、CFTC 持仓。
如果关心更大的市场预期，它还能拉 Kalshi 和 Polymarket 这类预测市场数据。

它不是问市场怎么看。
它是在问，资金怎么动，价格怎么走，期权怎么定价，机构怎么披露，宏观预期怎么变化。

问题理解 Agent 先拆题，判断你问的是个股、板块，还是全市场扫描。
信息 Agent 去收集证据。
多头 Agent 只负责找上涨逻辑。
空头 Agent 只负责挑刺，找风险和反证。
裁判 Agent 把两边放到一起，避免系统只听自己想听的话。

风控 Agent 再问一个现实问题：你拿多少钱买，最多能亏多少，仓位该怎么放。
最后，总经理 Agent 才给出完整的交易计划。

它现在支持通用分析、A 股每日扫描、指定板块和指定个股。
你可以扫描全市场，也可以指定半导体板块，让系统围绕候选股票跑完整条分析链路。
页面上能看到每个 Agent 的阶段输出：问题怎么被理解，数据怎么被收集，多头怎么讲，空头怎么反驳，风控怎么限制，最后怎么形成计划。

市场不是靠一个系统就能打穿的。
但它至少能帮我们做一件事。
在被情绪带着跑之前，先停下来，看一眼真实发生了什么。
不要看他说了什么。
要看他做了什么。
