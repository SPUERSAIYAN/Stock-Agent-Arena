事情是这样的。

做股票最坑的一件事是什么？

不是信息少。

是信息太多。

研报说它有空间，新闻说它有利好，KOL 说它要起飞，评论区说它已经完了。

每个人都在说。

但我越来越觉得，投研里有一句话特别重要。

不要看他说了什么。

要看他做了什么。

所以我做了 这个项目。

它不是只把一堆观点丢给模型，让模型帮你总结一下。

这个项目真正干的事情，是先去找数据。

美股这边，它可以看日线、周线、期权、EDGAR 财报和公告。

A 股这边，它可以看腾讯行情、指数数据、本地 A 股股票池、板块概念，还可以接 Tushare 和 mootdx 这类数据源。

宏观这边，它会看美债收益率、汇率、恐惧贪婪指数、CME FedWatch、CFTC 持仓。

如果你关心更大的市场预期，它还能拉 Kalshi、Polymarket 这类预测市场数据。

你会发现，它不是在问市场怎么看。

它是在问，资金怎么动，价格怎么走，期权怎么定价，机构怎么披露，宏观预期怎么变化。

也就是那句话。

不要看他说了什么。

要看他做了什么。

问题理解 Agent 先拆题。

你到底是在问某只股票，某个板块，还是全市场扫描。

信息 Agent 去收集数据。

多头 Agent 只负责找上涨逻辑。

空头 Agent 只负责挑刺，找风险，找反证。

裁判 Agent 把两边放到一起，不让系统只听自己想听的话。

风控 Agent 再问一个很现实的问题，你拿多少钱买，最多能亏多少，仓位该怎么放。

最后，总经理 Agent 才给出一个完整的交易计划。

说真的，我自己觉得这里最有意思的，不是最后那个买不买。

而是中间这条链路。

因为它会逼你把一句很模糊的话，拆成可以检查的证据。

上涨不是因为大家都说看好。

而是价格有没有走出来，成交有没有配合，期权有没有变化，财报有没有支撑，板块有没有共振。

下跌也不是因为评论区悲观。

而是风险有没有变大，宏观预期有没有转向，资金有没有撤，空头观点有没有证据。

这才是我想做的东西。

把投研从听故事，变成查行为。

它现在支持通用分析、A 股每日扫描、指定板块、指定个股。

你可以输入一个任务，比如扫描全市场，找出未来一个月值得研究的 A 股标的。

也可以指定半导体板块，让它围绕板块里的候选股票跑完整条分析链路。

页面上能看到每个 Agent 的阶段输出。

问题怎么被理解，数据怎么被收集，多头怎么讲，空头怎么反驳，风控怎么限制，最后怎么形成计划。

当然，市场不是靠一个系统就能打穿的。

但我觉得它至少能帮我们做一件很重要的事。

在被情绪带着跑之前，先停下来，看一眼真实发生了什么。

不要看他说了什么。

要看他做了什么。

这就是 这个项目做的事情。
